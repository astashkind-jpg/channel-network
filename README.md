# Бот сети Telegram-каналов — полная инструкция

Один бот ведёт сразу все каналы сети. Каждый вечер он готовит посты на завтра, присылает вам **одно сообщение-сводку**
и потом сам публикует посты по расписанию. Если вы не ответили на сводку в течение 3 часов, посты выходят автоматически.
Исключение — каналы с ручным утверждением: их посты выходят только после вашего ✅.

Инструкция рассчитана на человека, который делает это впервые. Идите по шагам сверху вниз, ничего не пропуская.

## 1. Как это устроено

```
                 каждый вечер ~18:40 (МСК)
GitHub Actions ──────────────────────────────►  «План на завтра»
                                                 • ИИ пишет тексты (Yandex AI Studio: DeepSeek, Qwen, Alice AI…)
                                                 • YandexART рисует картинки (запасной — Pixabay)
                                                 • чужие каналы — видео (по желанию)
                                                 • строки кросс-пиара, каталог по воскресеньям
                                                        │
                                                        ▼
                                   Вам в Telegram: сводка с кнопками
                                   [✅ Утвердить всё] [👀 Посмотреть]
                                                        │
                 каждые 30 минут                        ▼
GitHub Actions ──────────────────────────────►  «Кнопки и публикация»
                                                 • читает ваши нажатия
                                                 • через 3 ч без ответа утверждает сам
                                                 • публикует посты, время которых пришло
```

**Где что живёт:**
- **Код и настройки** — в вашем репозитории на GitHub. Настройки каналов лежат в файле `config/channels.yaml`.
- **Ключи и пароли** — в «секретах» GitHub. Их никто не видит, даже вы после сохранения.
- **Запуск** — GitHub Actions, бесплатные «роботы» GitHub, которые запускают бота по расписанию. Компьютер держать включённым не нужно.
- **Память бота** (что запланировано, что опубликовано, какие темы уже были) — папка `state/` в том же репозитории. Бот сам сохраняет её после каждого запуска.

**Каналы сети (уже настроены в `config/channels.yaml`):**

| Ключ | Канал | Тема | Модель | Утверждение |
|---|---|---|---|---|
| `auto` | 🚗 Под капотом | авто-лайфхаки, ремонт | общая | авто |
| `diy` | 🔨 Руки из плеч | ремонт, самоделки | общая | авто |
| `intimacy` | 🍒 Между нами | отношения и сексуальность, 18+ | общая | авто |
| `food` | 🥗 Вкусно и полезно | рецепты, ПП | общая | авто |
| `nature` | 🐾 Дикая планета | природа, животные | общая | авто |
| `history` | 📜 Было время | история, СССР, ностальгия | общая | авто |
| `afterdark` | 🌶 После полуночи | юмор 18+ | общая | **только ручное** |
| `cards` | 💐 Открытка дня | открытки | общая | авто |

Каналы делятся на два **кластера**: `main` (основные) и `adult` (18+). Кросс-пиар и каталог работают только внутри
своего кластера: основной канал никогда не рекламирует 18+ канал, и наоборот.

«Общая» модель — та, что указана в `config/network.yaml` (`default_model`, по умолчанию DeepSeek V4.1 Flash).
Любому каналу можно назначить свою — см. [шаг 5](#шаг-5-выбор-моделей-ии).

**Ключ** — короткое латинское имя канала. Им пользуются команды бота, например `/pause auto`.

## 2. Что понадобится и сколько стоит

**Аккаунты (все бесплатные):**
- Telegram — ваш обычный аккаунт.
- GitHub — github.com.
- Yandex Cloud — console.yandex.cloud (тот же, что для новостного бота, если он уже есть). Один ключ даёт доступ ко всем моделям: DeepSeek, Qwen, Alice AI, YandexGPT.
- Pixabay — pixabay.com и Pexels — pexels.com (бесплатные фотостоки).
- По желанию — второй аккаунт Telegram на отдельный номер, для репоста видео (шаг 11).

**Время на настройку:** 40–60 минут один раз, затем по 5 минут на подключение каждого канала.

**Ежемесячные расходы (примерно, сверьте с текущими тарифами):**

| Что | Сколько | Цена |
|---|---|---|
| GitHub Actions | ~1700 мин из 2000 бесплатных | 0 ₽ |
| Yandex AI Studio — тексты | ~24 поста в день | порядка сотен рублей (зависит от модели) |
| Pixabay, Pexels, Openverse — картинки | ~25 в день | 0 ₽ |
| YandexART — по желанию | ~20 картинок в день | платно, по тарифу Yandex Cloud; по умолчанию выключено |

## Шаг 1. Создать бота в Telegram

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Запустить» / «Start».
2. Отправьте команду `/newbot`.
3. BotFather спросит **имя бота** — это видят люди. Например: `Сеть каналов — помощник`.
4. Затем спросит **username** — латиницей, должен заканчиваться на `bot`. Например: `my_network_helper_bot`.
   Если занят — придумайте другой.
5. BotFather пришлёт сообщение с **токеном** вида:
   ```
   7412345678:AAH3kd9F...длинная_строка
   ```
   Это **TG_BOT_TOKEN**. Скопируйте и сохраните в заметки — понадобится на шаге 8.
   ⚠️ Токен — это пароль от бота. Никому его не показывайте и не публикуйте.
6. Необязательно, но удобно — меню команд. Отправьте BotFather `/setcommands`, выберите своего бота и отправьте одним сообщением:
   ```
   check - проверка: ИИ, фотостоки, каналы
   status - что запланировано и опубликовано
   channels - список каналов
   pause - остановить канал: /pause auto или /pause all
   resume - возобновить: /resume auto или /resume all
   preview - пробный пост: /preview food
   help - справка
   ```
7. **Обязательно:** найдите своего нового бота по username, откройте чат с ним и нажмите **«Запустить» / «Start»**.
   Без этого бот не сможет писать вам сводки: Telegram запрещает ботам писать первыми.

## Шаг 2. Узнать свой chat id

Бот должен знать, кому присылать сводки и чьи нажатия кнопок принимать. Это ваш числовой id в Telegram.

1. Найдите в Telegram **@userinfobot** и нажмите «Запустить».
2. Он ответит сообщением, где есть строка `Id: 123456789`.
3. Это число — **ADMIN_CHAT_ID**. Сохраните его.

> Только этот аккаунт сможет нажимать кнопки и давать команды боту. Чужие нажатия бот игнорирует.

## Шаг 3. Служебный канал «Склад медиа»

Бот заранее, ещё при подготовке плана, загружает картинки и видео в отдельный приватный канал. Потом и в
предпросмотре, и при публикации он берёт файл оттуда. Читать этот канал вам не нужно.

1. В Telegram: **карандаш / «Новое сообщение» → «Создать канал»**.
2. Название — любое, например `Склад медиа`. Описание можно не заполнять.
3. Тип канала — **Частный** (приватный).
4. Когда Telegram предложит добавить подписчиков — пропустите.
5. Откройте канал → нажмите на название → **«Управление каналом» → «Администраторы» → «Добавить администратора»**.
6. В поиске введите username вашего бота (из шага 1), выберите его.
7. Права: оставьте включённым **«Публикация сообщений»**, остальное не важно. Нажмите «Сохранить» / галочку.

**Как узнать id этого канала (STORAGE_CHAT_ID)** — выберите один способ:

- **Способ А (сразу):** напишите в канале любое сообщение, нажмите на него → **«Переслать»** → перешлите его боту
  **@userinfobot**. Он ответит, в ответе будет id вида `-1001234567890`. Это **STORAGE_CHAT_ID** — вместе с минусом.
- **Способ Б (после запуска, шаг 9):** напишите в канале `/id`. В течение 30 минут бот ответит в канале:
  `id этого канала: -100…`. Скопируйте и удалите оба сообщения.

> Пока STORAGE_CHAT_ID не задан, бот работает, но картинки отправляет прямыми ссылками, а **видео не публикует вовсе**.

## Шаг 4. Ключ Yandex AI Studio

> Если для новостного бота у вас уже есть API-ключ Yandex Cloud и id каталога, можно взять их — переходите к шагу 5.

Нужны два значения: **YANDEX_FOLDER_ID** (id каталога) и **YANDEX_API_KEY** (ключ).

### 4.1. Платёжный аккаунт
1. Откройте **console.yandex.cloud** и войдите через Яндекс ID.
2. Если облака ещё нет — согласитесь с условиями, облако и каталог `default` создадутся сами.
3. Слева **«Биллинг»** (Billing) → создайте платёжный аккаунт и привяжите карту. Без активного платёжного аккаунта
   нейросети не работают. Новым аккаунтам обычно дают стартовый грант.

### 4.2. id каталога
1. На главной странице консоли слева вверху выберите облако → каталог (обычно `default`).
2. Рядом с названием каталога есть id вида `b1gabc123def456ghi78` — нажмите на значок копирования.
   Это **YANDEX_FOLDER_ID**.

### 4.3. Сервисный аккаунт и ключ
1. В каталоге слева: **«Сервисные аккаунты»** (или «Identity and Access Management» → «Сервисные аккаунты»).
2. **«Создать сервисный аккаунт»**:
   - Имя: `channel-network-bot`
   - **Роли в каталоге:** добавьте роль `ai.languageModels.user` (тексты). Если позже захотите платные
     картинки YandexART — добавьте ещё `ai.imageGeneration.user`
   - Нажмите «Создать».
3. Откройте созданный аккаунт → вверху **«Создать новый ключ» → «Создать API-ключ»**.
4. Если спрашивает **область действия** (scope) — выберите `yc.ai.languageModels.execute` (и
   `yc.ai.imageGeneration.execute`, если планируете YandexART). Срок действия — без ограничения или на год.
5. Нажмите «Создать». Появится **секретный ключ** вида `AQVN...`. Это **YANDEX_API_KEY**.
   ⚠️ Он показывается **один раз** — скопируйте сразу.

Этот ключ работает со **всеми** моделями Yandex AI Studio — и с моделями Яндекса, и со сторонними (DeepSeek, Qwen),
а также с генерацией картинок YandexART.

> **Если ключ уже был создан раньше только с ролью `ai.languageModels.user`:** откройте сервисный аккаунт →
> добавьте роль `ai.imageGeneration.user`, затем создайте **новый** API-ключ с обеими областями действия и замените
> секрет `YANDEX_API_KEY` в GitHub. Пока этого не сделать, бот будет брать картинки с Pixabay.

## Шаг 5. Выбор моделей ИИ

Ничего получать не нужно — модели работают с ключом из шага 4. Здесь только выбор, какой модели писать посты.

### Доступные модели (Yandex AI Studio, октябрь 2026)

| Имя для настроек | Что это | Комментарий |
|---|---|---|
| `deepseek-v4.1-flash` | DeepSeek V4.1 Flash | **по умолчанию**: хороший русский, быстрый, недорогой |
| `qwen3.6-35b-a3b` | Qwen 3.6 35B (Alibaba) | альтернатива, стоит сравнить на 18+ каналах |
| `aliceai-llm` | Alice AI LLM (Яндекс) | сильная модель Яндекса, строже к «чувствительным» темам |
| `aliceai-llm-flash` | Alice AI LLM Flash | облегчённая и дешёвая версия |
| `yandexgpt-5.1` | YandexGPT Pro 5.1 | классическая модель Яндекса |

> Яндекс периодически заменяет модели новыми версиями. Например, `deepseek-v4-flash` и `yandexgpt-5-lite` отключат
> 15 ноября 2026 года. Если в логе появится ошибка `HTTP 404` про модель, поставьте новую версию из списка моделей в
> документации Yandex AI Studio.

### Как поменять модель
- **Для всех каналов сразу:** `config/network.yaml` → строка `default_model: "deepseek-v4.1-flash"`.
- **Для одного канала:** в `config/channels.yaml` у нужного канала заполните `model`, например:
  ```yaml
      model: "qwen3.6-35b-a3b"
  ```
  Пустое значение `model: ""` — канал использует общую модель.

### Как сравнить модели, ничего не меняя
Команда `/preview ключ модель` пришлёт пробный пост канала выбранной моделью. В канал он не уходит. Например:
```
/preview auto deepseek-v4.1-flash
/preview auto aliceai-llm
/preview intimacy qwen3.6-35b-a3b
```
Сравните тексты и впишите лучшую модель в настройки.

**18+ каналы.** Все модели работают по правилам платформы Яндекса, поэтому на темы 18+ любая может иногда
отказать. Такие посты попадут в раздел «⚠️ Не получилось» вечерней сводки. Если отказов много у одной модели,
попробуйте другую через `/preview`.

## Шаг 6. Ключи фотостоков (картинки)

Картинки берутся из **бесплатных** фотостоков. Бот перебирает их по порядку, пока не найдёт фото по теме поста:

| Источник | Ключ | Подпись в посте |
|---|---|---|
| **Pixabay** | нужен (бесплатно) | не нужна |
| **Pexels** | нужен (бесплатно); сейчас Pexels временно не выдаёт новые ключи — можно пропустить | «📷 Pexels» |
| **Wikimedia Commons** | не нужен | для фото под CC BY / BY-SA — «📷 Автор, лицензия / Wikimedia Commons» |
| **Openverse** | не нужен | для CC BY / BY-SA — «📷 Автор, лицензия» |

Бот ищет во всех источниках сразу и берёт фото, где в тегах или описании есть предмет поста. Затем **ИИ со
зрением** (модель Qwen в вашем Yandex AI Studio) смотрит на 6 лучших фото и выбирает то, где предмет действительно
виден. Фото с лицензиями «только некоммерческое использование» (NC) и «без изменений» (ND) не берутся.

Если точного фото нет нигде, бот берёт тематическое фото канала (`image_fallback`, например «car» для
«Под капотом»). Так **у каждого поста будет картинка**.

### 6.1. Pixabay (PIXABAY_KEY)
1. Зарегистрируйтесь на **pixabay.com** (кнопка «Join»), подтвердите почту.
2. Откройте **pixabay.com/api/docs/** (войдя в аккаунт).
3. В разделе **«Search Images» → «Parameters»** у параметра `key` будет ваш ключ, выделенный зелёным.
   Это **PIXABAY_KEY**.

### 6.2. Pexels (PEXELS_KEY)
1. Зарегистрируйтесь на **pexels.com** (кнопка «Join»), подтвердите почту.
2. Откройте **pexels.com/api/** → кнопка **«Get Started»** / «Your API Key».
3. Заполните короткую форму: назначение — например, «Telegram channels with daily posts», сайт можно указать
   ссылку на канал. Отметьте согласие с условиями → **«Generate API Key»**.
4. Скопируйте ключ (длинная строка из букв и цифр). Это **PEXELS_KEY**.

Лимит Pexels — 200 запросов в час, бот укладывается с большим запасом.

### 6.3. Openverse
Ничего делать не нужно — работает без ключа.

### Платная альтернатива: YandexART
Бот умеет рисовать картинки точно под текст через YandexART (Yandex AI Studio). Это платно, по умолчанию
выключено. Как включить — раздел [Картинки](#картинки) в «Настройке каналов».

## Шаг 7. Репозиторий на GitHub

### 7.1. Распаковать архив
Распакуйте `channel-network.zip` у себя на компьютере. Получится папка `channel-network`, внутри:
```
.github/   bot/   config/   scripts/   state/   tests/   README.md   requirements.txt   .gitignore
```
> Папки `.github` и файл `.gitignore` могут быть **не видны**: они «скрытые», потому что начинаются с точки.
> - **Windows:** в Проводнике «Вид» → «Показать» → «Скрытые элементы».
> - **macOS:** в Finder нажмите `Cmd + Shift + .` (точка).

### 7.2. Создать репозиторий
1. Войдите на **github.com** → справа вверху **«+» → «New repository»**.
2. **Repository name:** `channel-network`.
3. Выберите **Private** (приватный). Подробнее о выборе — в разделе [Расписание](#расписание-и-как-его-поменять).
4. Галочки «Add a README», «.gitignore», «license» **не ставьте**.
5. **«Create repository»**.

### 7.3. Загрузить файлы
1. На странице пустого репозитория нажмите ссылку **«uploading an existing file»**.
2. Откройте папку `channel-network` на компьютере, **выделите всё её содержимое** (не саму папку!) и перетащите в окно браузера.
3. Дождитесь, пока загрузятся все файлы, внизу нажмите **«Commit changes»**.
4. **Проверьте**, что в репозитории есть папка `.github`. Внутри должна быть папка `workflows` с тремя файлами:
   `plan.yml`, `tick.yml`, `report.yml`.

**Если папки `.github` нет** (браузер её пропустил), создайте три файла вручную:
1. **«Add file» → «Create new file»**.
2. В поле имени напишите `.github/workflows/plan.yml` — слеши сами превратятся в папки.
3. Откройте этот файл на компьютере в Блокноте, скопируйте всё и вставьте в окно GitHub → «Commit changes».

## Шаг 10. Подключение каналов по очереди

Рекомендуемый порядок: `auto` → `diy` → `intimacy` → `food` → `nature` → `history` → `afterdark` → `cards`.
Лучше подключать по одному-два канала в неделю: так проще следить за качеством постов.

### 10.1. Создать канал в Telegram
1. **«Создать канал»**. Название и описание возьмите из таблицы ниже (или придумайте свои).
2. Тип канала:

   Для старта рекомендую **публичный**: проще настроить, и `chat_id` — это просто `@адрес`.
3. Добавьте бота администратором, как в шаге 3: «Управление каналом» → «Администраторы».
   Права: **«Публикация сообщений»** — обязательно, **«Изменение сообщений»** — желательно.
4. Поставьте аватарку. Её можно сгенерировать в любой нейросети для картинок.

| Ключ | Название | Описание канала (для поля «Описание») |
|---|---|---|
| `auto` | Под капотом | Авто-лайфхаки, уход за машиной и ремонт своими руками 🚗 |

| `nature` | Дикая планета | Удивительные животные и чудеса природы 🐾 |
| `history` | Было время | История, СССР и вещи из нашего детства 📜 |
| `afterdark` | После полуночи | 18+ Юмор для взрослых 🌶 |

### 10.2. Пригласительная ссылка (для кросс-пиара)
1. «Управление каналом» → **«Пригласительные ссылки»** → **«Создать ссылку»**.
2. Назовите её `сеть` (видно только вам) → «Создать». Скопируйте ссылку вида `https://t.me/+AbCdEf123`.

Отдельная ссылка нужна, чтобы видеть, сколько людей пришло по кросс-пиару: Telegram считает вступления по каждой ссылке.

### 10.3. Вписать канал в настройки
1. На GitHub откройте файл **`config/channels.yaml`** → справа вверху значок **карандаша** (Edit this file).
2. Найдите блок своего канала (например, `- key: auto`) и заполните две строки:
   ```yaml
       chat_id: "@pod_kapotom_auto"
       invite_link: "https://t.me/+AbCdEf123"
   ```
   - Для публичного канала `chat_id` — это `@адрес` канала.
   - Для частного — id вида `-100…`. Его можно узнать командой `/id` в канале или пересылкой поста в @userinfobot (см. шаг 3).
3. Справа вверху **«Commit changes…» → «Commit changes»**.

⚠️ **Правила редактирования YAML:**
- Значения пишите **в кавычках**: `"@channel"`.
- **Не меняйте отступы** — пробелы в начале строки важны. Табуляцию использовать нельзя.
- Двоеточие после названия поля и пробел после двоеточия обязательны: `chat_id: "@x"`.

Ошибка в файле видна в следующем запуске Actions (красный крестик с текстом про `yaml`). Исправьте строку — и всё заработает.

## Шаг 11. Видео из чужих каналов (по желанию)

Бот-аккаунт не может читать чужие каналы, поэтому видео забирает **обычный аккаунт Telegram** через официальный API.
Пока этот шаг не сделан, видео-рубрики автоматически заменяются текстовыми постами.

### 11.1. Отдельный аккаунт
Настоятельно рекомендую **второй аккаунт** на отдельный номер (вторая SIM или виртуальный номер), а не личный.
Если аккаунт заблокируют за активность через API, пострадает только он.
Включите на нём двухэтапную аутентификацию: «Настройки → Конфиденциальность → Облачный пароль».

### 11.2. api_id и api_hash
1. В браузере откройте **my.telegram.org** и войдите с номером **второго** аккаунта (код придёт в Telegram).
2. **«API development tools»**.
3. Заполните форму: App title `network`, Short name `network123`, Platform — `Desktop`. Остальное можно оставить пустым.
4. «Create application». Появятся **App api_id** (число) → **TG_API_ID** и **App api_hash** (строка) → **TG_API_HASH**.

### 11.3. Получить TG_SESSION (на своём компьютере)
**Windows:**
1. Установите Python с **python.org** → Downloads. При установке **обязательно** поставьте галочку
   **«Add Python to PATH»**.
2. Откройте папку `channel-network`, в адресной строке Проводника напишите `cmd` и нажмите Enter — откроется командная строка.
3. Выполните по очереди:
   ```
   pip install telethon
   python scripts/make_session.py
   ```

**macOS:**
1. Откройте «Терминал», перейдите в папку: `cd ~/Downloads/channel-network` (или где она у вас лежит).
2. Выполните:
   ```
   pip3 install telethon
   python3 scripts/make_session.py
   ```

Скрипт спросит:
- `api_id:` — вставьте TG_API_ID;
- `api_hash:` — вставьте TG_API_HASH;
- номер телефона второго аккаунта в формате `+79991234567`;
- код из Telegram (придёт в приложение второго аккаунта);
- облачный пароль, если он включён.

В конце скрипт выведет длинную строку. Это **TG_SESSION**: скопируйте её **целиком** в секрет GitHub (шаг 8).
⚠️ Эта строка — полный доступ к аккаунту. Не отправляйте её никому и не сохраняйте в файлах репозитория.

### 11.4. Источники видео
1. Подпишите **второй аккаунт** на каналы, откуда брать видео. Для каждой рубрики выберите 3–5 каналов с хорошими
   видео по теме.
2. В `config/channels.yaml` впишите их в `video_sources` нужного канала:
   ```yaml
       video_sources: ["@source_channel_1", "@source_channel_2", "@source_channel_3"]
   ```
3. Commit changes.

**Как бот выбирает видео:**
- смотрит последние посты источников не старше 4 дней (`video_max_age_days` в `config/network.yaml`);
- пропускает посты со словами-признаками рекламы (`ad_markers`: «erid», «реклама», «промокод», «казино» и т. п.)
  и со ссылками-приглашениями в другие каналы;
- пропускает видео больше 49 МБ (ограничение Telegram для ботов);
- берёт самые просматриваемые и никогда не повторяет одно и то же видео;
- пишет свою короткую подпись и добавляет строку **«📎 Источник: @канал»**.

⚠️ Репост чужих видео — серая зона: правообладатель может пожаловаться, и Telegram удалит пост или канал.
Указание источника снижает риск, но не убирает его. Для канала «После полуночи» репосты выходят **только после
вашего ✅** — проверяйте их внимательно.

## Ежедневная работа

### Вечерняя сводка (~18:40 по Москве)

```
📋 План на 24 октября, суббота

🚗 Под капотом — 3 (2 фото, 1 видео)
🔨 Руки из плеч — 3 (3 фото)
🍒 Между нами — 3 (3 фото)
...
⏳ Без ответа посты выйдут автоматически после 21:40.
✋ Выйдут только после вашего ✅: После полуночи — 3.
⚠️ Не получилось:
• Было время, Как жили в СССР: Yandex HTTP 429…

[✅ Утвердить всё]  [👀 Посмотреть]
```

**Три варианта действий:**

| Что сделать | Что будет |
|---|---|
| Ничего | Через 3 часа все посты, кроме ручных (✋), утвердятся и выйдут по расписанию |
| **✅ Утвердить всё** | Утверждаются все посты, **включая ручные** ✋ |
| **👀 Посмотреть** | Бот пришлёт каждый пост в том виде, как он выйдет, с кнопками |

**Кнопки под каждым постом в режиме «Посмотреть»:**
- **✅** — утвердить этот пост;
- **❌** — не публиковать. Отменить можно кнопкой «↩️ Вернуть»;
- **🔄 Заменить** — бот напишет другой пост на это же время. Новый вариант придёт отдельным сообщением.

Нажатия обрабатываются при ближайшем запуске, раз в 30 минут. Значок на кнопке меняется именно тогда.

**Ручной канал (✋):** если до времени поста прошло 12 часов, а ✅ так и не было, пост сгорает (статус ⌛) и не выйдет.

### Сообщения об ошибках
Если пост не удалось опубликовать (например, бота убрали из админов), придёт сообщение «⚠️ Не опубликовалось»
с указанием поста и причины.

### Еженедельный отчёт (понедельник ~10:15)
По каждому каналу: подписчики и прирост за неделю, сколько постов вышло и отклонено, средние и максимальные
просмотры (просмотры — только если настроен шаг 11).

### Посты-каталоги (воскресенье ~12:00)
В каждом канале выходит пост «Наши каналы» со ссылками на остальные каналы того же кластера.

## Настройка каналов и рубрик

Все настройки каналов — в `config/channels.yaml`, общие — в `config/network.yaml`. Править прямо на GitHub
(значок карандаша → Commit changes). Изменения вступают в силу со следующего запуска.

### Поля канала

```yaml
  - key: auto                     # латинский ключ, уникальный; используется в командах
    enabled: true                 # false — канал выключен
    title: "Под капотом"          # название (в сводках и кросс-пиаре)
    chat_id: "@pod_kapotom"       # @адрес или -100… id
    invite_link: "https://t.me/+…" # ссылка для кросс-пиара; пусто — канал не рекламируется
    tagline: "авто-лайфхаки…"     # строка о канале в кросс-пиаре
    emoji: "🚗"
    cluster: main                 # main или adult
    model: ""                     # модель AI Studio; пусто — default_model
    auto_approve: true            # false — только ручное ✅
    signature: ""                 # строка в конце каждого поста, например "❤️"
    windows: ["08:00-09:30", "13:00-14:30", "19:00-21:00"]   # окна по Москве
    video_sources: []
    persona: |                    # «голос» автора — главное, что определяет стиль
      Ты — автор канала…
    rubrics:
      - name: "Лайфхак"
        weight: 3                 # чем больше, тем чаще рубрика
        prompt: "Задание для ИИ…"
      - name: "Видео"
        type: video
        weight: 2
```

### Частые правки

**Больше или меньше постов в день.** Количество окон в `windows` = количество постов. Добавьте окно — будет 4 поста:
```yaml
    windows: ["08:00-09:30", "12:00-13:00", "16:00-17:00", "19:00-21:00"]
```
Время внутри окна каждый день выбирается случайно, чтобы посты не выходили по минутам «как робот».

**Изменить стиль.** Правьте `persona`: кто автор, для кого пишет, каким тоном. Пишите своими словами, как
объясняли бы живому копирайтеру. Проверяйте результат командой `/preview ключ`.

**Новая рубрика.** Добавьте блок в `rubrics`:
```yaml
      - name: "Вопрос подписчика"
        weight: 1
        prompt: "Частый вопрос о … и подробный ответ."
```
Дополнительные поля рубрики:
- `image: false` — пост без картинки;
- `slots: [0]` — рубрика ставится только в первое окно (нумерация с 0). Так в «Открытке дня» «Доброе утро»
  выходит утром, а «Спокойной ночи» — вечером.

**Ручное утверждение для канала.** `auto_approve: false`.

**Время на согласование.** `review_hours: 3` в `config/network.yaml`.

**Новый канал.** Скопируйте целиком блок любого канала (от `- key:` до следующего `- key:`), вставьте в конец
файла, смените `key` на новый уникальный и заполните поля.

**Выключить канал.** `enabled: false` или команда `/pause ключ`.

### Картинки
- **У каждого поста есть картинка.** ИИ даёт четыре поисковых запроса про предмет поста — от точного
  («coolant reservoir») к чуть более общему («car engine bay»). Бот ищет по ним в Pixabay, Pexels, Wikimedia Commons
  и Openverse и оставляет фото, где в тегах или описании есть предмет. Если ничего точного нет — тематическое
  фото канала (`image_fallback`).
- `image_check: true` в `config/network.yaml` — ИИ со зрением выбирает из найденных фото то, где предмет виден
  крупно и узнаваемо. Оплачивается из баланса Yandex AI Studio по тарифу модели Qwen (небольшие суммы за пост —
  сверьте в тарифах). Выключить: `image_check: false` — тогда фото выбирается только по тегам.
- `image_category` у канала — категория Pixabay (`transportation`, `food`, `animals`, `nature`, `buildings`…).
  Сужает поиск.
- `image_fallback` у канала — запрос для тематического фото по-английски (`car`, `flowers bouquet`…).
- Фото не повторяются в одном канале.
- Если текст длинный и не помещается в подпись к фото (лимит Telegram — 1024 знака), ИИ его сокращает. Если
  и после этого не влезло — фото и текст выйдут двумя сообщениями подряд.
- Если картинка всё же не нашлась (например, все фотостоки недоступны), пост попадёт в «⚠️ Не получилось» в сводке
  — нажмите у него 🔄 Заменить.
- В пробном посте (`/preview`) в заголовке видно, откуда картинка: Pixabay, Pexels, Wikimedia, Openverse или YandexART.
- **YandexART (платно):** в `config/network.yaml` поставьте `image_source: "generate"` (или только у нужного
  канала в `channels.yaml`). Сервисному аккаунту Yandex понадобится роль `ai.imageGeneration.user` и API-ключ
  с областью `yc.ai.imageGeneration.execute` (см. шаг 4). Если генерация не удалась — бот возьмёт фото со стоков.

### Интеграция своих товаров
Например, сезонный совет про охлаждающую жидкость в «Под капотом» с упоминанием вашего бренда. Добавьте
рубрику с `weight: 1`, в `prompt` опишите продукт и попросите упоминать его естественно, в контексте совета.
По закону о рекламе нативное упоминание собственного товара в канале может потребовать маркировки — уточните
этот момент до запуска.

## Расписание и как его поменять

| Workflow | Когда (Москва) | cron (UTC) | Файл |
|---|---|---|---|
| План на завтра | ежедневно ~18:37 | `37 15 * * *` | `.github/workflows/plan.yml` |
| Кнопки и публикация | каждые 30 мин (:07 и :37) | `7,37 * * * *` | `.github/workflows/tick.yml` |
| Недельный отчёт | понедельник ~10:13 | `13 7 * * 1` | `.github/workflows/report.yml` |

⚠️ **Время в cron указывается по UTC**: Москва = UTC + 3. Чтобы сводка приходила в 20:00 по Москве, нужно 17:00 UTC: `0 17 * * *`.
GitHub иногда запускает расписание с опозданием на 5–20 минут — это нормально.

**Приватный или публичный репозиторий:**
- **Приватный** (по умолчанию): 2000 бесплатных минут в месяц. Проверка раз в 30 минут укладывается с запасом
  (~1700 мин). Чаще ставить нельзя — минуты закончатся, и бот встанет до начала следующего месяца.
- **Публичный**: минуты не ограничены, в `tick.yml` можно поставить `*/10 * * * *` (раз в 10 минут). Минус: все
  видят код, настройки и папку `state/` с текстами постов, в том числе 18+. Ключи при этом остаются скрытыми.

Сколько минут израсходовано: на github.com нажмите на аватарку → **Settings → Billing and plans** → раздел Actions.

## Если что-то не работает

Сначала посмотрите лог: **Actions** → нужный запуск (❌) → шаг с ошибкой → красный текст внизу.

| Симптом / текст ошибки | Причина | Что сделать |
|---|---|---|
| Сводка не пришла вечером | бот не может писать вам | напишите боту `/start` (шаг 1, п. 7); проверьте `ADMIN_CHAT_ID` |
| В логе `ADMIN_CHAT_ID не задан` | нет секрета | добавьте секрет (шаг 8) |
| Бот не реагирует на кнопки/команды | обрабатывает раз в 30 минут | подождите или запустите «Кнопки и публикация» вручную |
| Бот не реагирует совсем | неверный токен | в логе будет `Unauthorized` → проверьте `TG_BOT_TOKEN` |
| `chat not found` | неверный `chat_id` или бот не в канале | проверьте адрес канала; бот должен быть админом |
| `not enough rights to send` | у бота нет права публикации | права администратора → «Публикация сообщений» |
| `Yandex HTTP 401` / `403` | неверный ключ или нет роли | проверьте `YANDEX_API_KEY`, роль `ai.languageModels.user`, `YANDEX_FOLDER_ID` |
| `Yandex HTTP 429` | слишком много запросов | бот повторяет сам; если часто — проверьте квоты в Yandex Cloud |
| `Yandex HTTP 402` или ошибки биллинга | закончились деньги | пополните баланс Yandex Cloud |
| `Yandex HTTP 404` про модель | модель отключена или опечатка | проверьте имя в `default_model` / `model`, см. шаг 5 |
| `модель вернула пустой ответ` | модель отказалась писать на тему | попробуйте другую модель для этого канала (шаг 5) |
| В сводке «без картинки» | фотостоки не ответили | проверьте `PIXABAY_KEY` и `PEXELS_KEY`; нажмите 🔄 Заменить |
| Картинка не по теме | ИИ дал неудачный запрос | 🔄 Заменить; при частых промахах уточните `image_category` и `image_fallback` канала |
| В логе `YandexART HTTP 401/403` | у ключа нет прав на картинки | шаг 4: роль `ai.imageGeneration.user` + новый ключ с областью `yc.ai.imageGeneration.execute` |
| Все картинки с Pixabay, а не YandexART | то же | см. строку выше |
| Видео не появляются | нет `TG_SESSION`/`STORAGE_CHAT_ID`/`video_sources` | шаги 3 и 11; в логе плана ищите «репост видео» |
| `для видео нужен STORAGE_CHAT_ID` | нет служебного канала | шаг 3 |
| Ошибка про `AuthKey` / `session` в логе | сессия Telethon устарела | заново `scripts/make_session.py`, обновите `TG_SESSION` |
| `yaml` / `ScannerError` в логе | ошибка в `channels.yaml` | проверьте отступы и кавычки в последней правке |
| `не удалось сохранить состояние` | нет прав на запись | шаг 7.4: «Read and write permissions» |
| Пост вышел дважды | не сохранилось состояние | шаг 7.4; проверьте, что шаг «Сохранить состояние» зелёный |
| Workflows не запускаются по расписанию | выключены или закончились минуты | Actions → включите workflow; проверьте минуты |
| Сводка пустая: «Постов нет» | ни у одного канала нет `chat_id` | шаг 10.3 |

**Экстренная остановка:** напишите боту `/pause all` и запустите «Кнопки и публикация» вручную. Если бот не
отвечает — Actions → «Кнопки и публикация» → кнопка «…» справа → **Disable workflow**. Публикации прекратятся
сразу. Включить обратно: там же → Enable workflow.

**Пересоздать план на завтра:** Actions → «План на завтра» → Run workflow → галочка «Пересоздать».

## Безопасность

- Все ключи храните **только в секретах GitHub**. Никогда не вписывайте их в файлы репозитория.
- Если ключ попал не туда (переслали, опубликовали) — сразу **перевыпустите** его:
  - токен бота — @BotFather → `/revoke`;
  - ключ Яндекса — удалите ключ сервисного аккаунта и создайте новый;
  - `TG_SESSION` — во втором аккаунте: «Настройки → Устройства» → завершите чужие сеансы, затем получите новую сессию.
- Нажимать кнопки и давать команды может только аккаунт с `ADMIN_CHAT_ID`.
- 18+ каналы: перед запуском убедитесь, что контент соответствует законам вашей страны и правилам Telegram.
  Бот настроен на просветительский тон и юмор без откровенных сцен, но ответственность за опубликованное —
  на владельце канала.

## Структура проекта

```
channel-network/
├── .github/workflows/
│   ├── plan.yml          ← «План на завтра»: ежедневно, план + сводка
│   ├── tick.yml          ← «Кнопки и публикация»: каждые 30 минут
│   └── report.yml        ← «Недельный отчёт»: понедельник
├── bot/
│   ├── main.py           ← точка входа: plan / tick / report
│   ├── planner.py        ← план на день и текст сводки
│   ├── approvals.py      ← кнопки и команды
│   ├── publisher.py      ← автоутверждение и публикация
│   ├── core.py           ← сборка постов, кросс-пиар, каталог
│   ├── ai.py             ← модели Yandex AI Studio (DeepSeek, Qwen, Alice AI…)
│   ├── images.py         ← картинки: YandexART и Pixabay
│   ├── reposter.py       ← видео из чужих каналов (Telethon)
│   ├── report.py         ← недельный отчёт
│   ├── diagnostics.py    ← команда /check
│   ├── tg.py             ← Telegram Bot API
│   ├── state.py          ← «память» бота в папке state/
│   ├── settings.py       ← чтение настроек и секретов
│   └── util.py           ← время, окна, разбор ответов ИИ
├── config/
│   ├── channels.yaml     ← ВСЕ НАСТРОЙКИ КАНАЛОВ
│   └── network.yaml      ← общие настройки
├── scripts/make_session.py  ← получение TG_SESSION (шаг 11)
├── state/                ← память бота (заполняется сама, не редактировать)
├── tests/test_bot.py     ← 50 автотестов
└── requirements.txt
```
